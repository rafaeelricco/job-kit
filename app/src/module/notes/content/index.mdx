Drop an `.mdx` or `.md` file into `src/module/notes/content/` and it becomes a
page — no loader or route edits needed.

## Pages

- [Getting Started](/notes/getting-started)

## Code blocks

Highlighted by Shiki at build time, with line numbers and dual light/dark
themes:

```ts
type NotePage = {
  path: string
  metadata: { title: string; description?: string }
  Component: ComponentType
}
```

## Extensions

| Extension | Format           | JSX allowed |
| --------- | ---------------- | ----------- |
| `.mdx`    | MDX              | yes         |
| `.md`     | CommonMark + GFM | no          |
