# Brand assets

Vector sources live in `app/public/brand/`; the preview catalog renders them from there, so there is no copy here to drift.

| Asset                                                  | Use                                                                                                 |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| `app/public/brand/mascot-mark.svg`                     | Head-only crop. Sidebar header (28px), sign-in header (56px), live SVG favicon                      |
| `app/public/brand/mascot-mark-dark.svg`                | Same crop with a light keyline; required on dark grounds (ink `#1d1d1d` is 1.00:1 on the dark card) |
| `app/public/brand/mascot.svg`                          | Full mascot; never below 32px                                                                       |
| `app/public/brand/wordmark.svg` / `wordmark-dark.svg`  | Wordmark alone                                                                                      |
| `app/public/brand/wordmark-tagline.svg` / `-dark.svg`  | Wordmark with "your job search, made simpler"                                                       |
| `app/public/brand/lockup.svg` / `lockup-dark.svg`      | Stacked mascot + wordmark                                                                           |
| `app/public/brand/lockup-horizontal.svg` / `-dark.svg` | Horizontal lockup; source of `job-kit-logo.png` (README hero)                                       |
| `app/public/brand/og-image.svg`                        | Social card; source of `og-image.png`                                                               |

Every favicon, app icon, OG image and logo PNG under `app/public/` is generated by `scripts/brand/render.py` (`permission-not-granted.png` is a hand-made illustration). Edit the SVG and rerun it; never hand-edit a PNG.
