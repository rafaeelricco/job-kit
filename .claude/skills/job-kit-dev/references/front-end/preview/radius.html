Corner radius · one default, three exceptions

0 · default Buttons, inputs, cards, dialogs, tables, badges, menus
4px · chip Inline identifier chip (<code>) only
6px · nav row Sidebar rows and account button only
full · pill Avatars, switch tracks, status dots, small clear buttons

There are no other radii; an in-between value is a bug. Removing a rounded-* class is preferred over setting it to a smaller step.
