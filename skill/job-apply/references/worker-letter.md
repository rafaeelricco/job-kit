# worker-letter

Caller pastes `### Letter plan` (with `### Ad formats`) + `### Forbidden claims` +
LETTER_TEXT + every staged free-text value and the question it answers + CONTRACT_LETTER
before this delta. Never a Fact path, never
`### Fit` or `### Left out`, never a flow file.

## Deltas

1. Open nothing — no file, no URL, no Profile root. The plan and the text in this brief
   are the whole evidence set: a claim you cannot land on a plan row is untraceable by
   definition, not a claim to go looking for.
2. Emit CONTRACT_LETTER checker output — exactly one Outcome. Findings only, then stop.
