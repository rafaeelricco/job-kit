# private/ — confidential only

Client and project names stay **only** under this folder. Never copy them into
CV, cover letters, public `data/`, or anything sent outside. Public docs use
domain phrasing only.

## Layout

| Path | Use |
| ---- | --- |
| `interview/` | Skim pack before a call (stories, tech, brief index) |
| `impact/` | Full PR / achievement memory |
| `projects/` | Per-client dossier (deep brief + links) |
